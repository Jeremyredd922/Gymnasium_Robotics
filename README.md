# Final Project

Deadline for pushing your commits to GitHub: 11:30AM (CST) on 2026-03-18

The goal of this final project is for you to exercise the skills you have developed with using AI-code assistants during this course.

You are free to choose a project topic that will be enjoyable for you.
You should endeavor to make it somewhat challenging: neither too easy nor too ambitious.

A good strategy is to start *early* and work on a *manageable* feature.
Get one feature working and tested first.
Then add one feature at a time until you have a satisfactory project.
Incremental work.

A bad strategy is to start with only 4 days to go, use up all of your usage on other tasks, to start with a feature that is too hard, or to stop after just doing one feature.

Requirements:
- You *must* work with either Claude Code or GitHub Copilot to develop your project.
- You *must* use spec-kit to develop your project's specification, architecture, implementation, etc.
- You *must* use Python and uv.
- You *must* have tests in your project.
- Your program *must* be developed with at least 4 features (uses of =/speckit.specify= ... =/speckit.implement=).
